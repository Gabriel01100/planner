# Experiencia Android

Cuatro destinos: Hoy, Agenda, Objetivos y Asistente. Configuración/estadísticas son acciones secundarias. Hoy prioriza próxima actividad, horario, duración, objetivo y comenzar/finalizar; el resto del día queda debajo. Los estados vacío, carga, error y guardado son explícitos. Los formularios de objetivo, sesión, recurso y actividad no se cierran antes de un guardado exitoso; los errores se conservan para corregir.

Agenda abre una grilla mensual real, con siete columnas, días adyacentes, indicador de hoy y títulos de actividades. Tocar un día abre la línea horaria; Semana muestra siete columnas desplazables y bloques posicionados por comienzo/duración. Día muestra horas, disponibilidad, bloqueos y sesiones completadas diferenciadas. Tocar un bloque abre el detalle con las acciones existentes. No es una lista agrupada por fecha. Hay navegación de períodos y regreso a hoy. No se implementó drag-and-drop.

Crear actividad muestra campos básicos primero; restricciones, recurrencia y dependencias por título quedan en opciones avanzadas. No se exponen UUID como controles de producto. Los bloques cortos tienen altura visual mínima para ser seleccionables; para cinco minutos esa altura no representa una escala exacta. Las celdas y eventos tienen descripciones de accesibilidad. Semana permite desplazamiento horizontal en pantallas pequeñas y las horas verticalmente; no se ocultan días fuera de pantalla sin posibilidad de acceder.

Aprendizaje requiere objetivo confirmado. Cronómetro mide tiempo transcurrido corregible, no concentración. Recursos no crean conocimiento automáticamente. Resultados evaluados y confianza declarada son opcionales y explícitos; no se muestra un porcentaje global ficticio de dominio.

Configuración contiene sincronización, exportación de ambas versiones de un conflicto, copias independientes, autorización acotada de horarios y vinculación OAuth. UI no pide claves de proveedor de IA. Share Intent siempre abre revisión y explica qué se envía. Las pruebas instrumentadas verifican flujos; no se afirma un estudio de usabilidad con participantes ni compatibilidad probada en todos los fabricantes.
